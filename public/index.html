Experimental pipeline for E2E testing

Action E2E Prototype

Local prototype for inspecting web projects, proposing user flows, reviewing acceptance criteria, generating Playwright tests, and consolidating results with support from local or remote models.

Pipeline

The complete workflow covered by the prototype, from project reading to final insights.

  1. 1
    Project selection

    Choose the directory and entry point.

  2. 2
    Inspection and understanding

    README, structure, manifests, and UI hints.

  3. 3
    Primary flows

    Hypotheses about the expected user journey.

  4. 4
    Acceptance criteria

    Human review and approval.

  5. 5
    Test generation

    Creation of Playwright artifacts.

  6. 6
    Execution

    Target application startup and test run.

  7. 7
    Results and insights

    Consolidation of pipeline observations.
